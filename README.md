# xrwvm-fullstack_developer_capstone

# Project Name: Best Cars Dealership

## Repository Name
xrwvm-fullstack_developer_capstone

## Project Description
Best Cars Dealership is a full-stack web application developed as part of the IBM Full Stack Application Development Capstone Project.

The application allows users to explore car dealerships, view dealer information, register and log in, and read and submit dealership reviews.

## Technologies Used
- Python
- Django
- React
- JavaScript
- HTML
- CSS
- REST APIs

## Main Features
- Dealership information and static pages
- User registration and login
- Browse available dealerships
- View dealership details
- Filter dealerships by state
- View and submit customer reviews
- Review sentiment analysis
